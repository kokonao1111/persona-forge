# 人格の画像

ここに画像を置くと、コードを触らずに反映される。
どの組み合わせがどの画像になるかは **ファイル名で決まる**。

## 使うキーワード

| 軸 | 画面の表示 | ファイル名に使う語 |
|---|---|---|
| 性格 | 素直 | `gentle` |
| | 心配性 | `anxious` |
| | 頑固 | `stubborn` |
| 態度 | ドS | `dom` |
| | ふつう | `neutral` |
| | ドM | `sub` |
| 性別 | 男の子 | `boy` |
| | 女の子 | `girl` |
| | 指定なし | `none` |

拡張子は `.png` `.webp` `.jpg` のどれでもいい。

## 置き場所

```
public/personas/
├── personality/    左の枠（性格を選ぶと出る）
├── attitude/       右の枠（態度を選ぶと出る）
└── face/           合成後（「この人にする」で出る）
```

## 探す順番

具体的なものから順に探し、無ければ一段ずつ大まかなものに落ちる。
**全部揃える必要はない。** 用意した分だけ効く。

### `face/` — 合成後

例：素直 × ドS × 女の子 を選んだとき

```
1. face/gentle-dom-girl.png   ← あればこれ
2. face/gentle-girl.png       ← 無ければこれ
3. face/gentle-dom.png        ← 無ければこれ
4. face/dom-girl.png          ← 無ければこれ
5. face/gentle.png            ← 無ければこれ
6. face/dom.png               ← 無ければこれ
7. attitude/dom-girl.png      ← 合成後を用意していなければ、右の枠の絵を流用する
8. attitude/dom.png
9. （どれも無ければ点線の枠）
```

つまり最小 **3枚**（`gentle` / `anxious` / `stubborn`）から始められる。
性別で描き分けたくなったら 9枚、態度まで描き分けたければ 27枚。
**途中まででも壊れない。**

### `personality/` — 左の枠

```
1. personality/gentle-girl.png
2. personality/gentle.png
```

### `attitude/` — 右の枠

```
1. attitude/dom-girl.png
2. attitude/dom.png
```

## 画像の仕様

- 縦長でも構わない。**上を基準に切り抜く**ので、顔が上のほうにある人物写真でも切れない
- 正方形なら切り抜きなしでそのまま出る
- 目安 512×512px 以上（大きく表示する場所があるため）
- **画面上は白黒に変換して表示される。** カラーで作っても構わないが、
  白黒にしたときに潰れない明暗差をつけておくこと
- 背景は透過でも塗りつぶしでもいい。透過なら黒背景に馴染む
